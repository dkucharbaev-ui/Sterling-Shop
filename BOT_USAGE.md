# 🤖 Psycho Stars Bot — Руководство по запуску

## Текущий режим: Обычный текстовый бот

> Mini App будет интегрирован позже. Сейчас бот работает в режиме обычного текстового бота с inline-кнопками.

---

## ⚙️ Необходимые переменные окружения

Создайте файл `.env` в корне проекта со следующими переменными:

```dotenv
# --- Обязательные ---
BOT_TOKEN=ваш_токен_от_BotFather
BOT_USERNAME=имя_вашего_бота_без_собачки
ADMIN_IDS=ваш_telegram_id

# --- Платёжные шлюзы ---
CRYPTOBOT_API_TOKEN=токен_от_CryptoBot
CRYPTOBOT_NETWORK=mainnet

LAVAPAY_SHOP_ID=uuid_магазина
LAVAPAY_SECRET_KEY=секретный_ключ
LAVAPAY_ADDITIONAL_KEY=дополнительный_ключ

# --- Опционально ---
DRY_RUN_FULFILLMENT=true   # true = без реальных выплат TON (для тестов)
```

---

## 🚀 Запуск бота

### 1. Активируйте виртуальное окружение

```bash
source ./venv/bin/activate
```

### 2. Запустите бота

```bash
PYTHONPATH="bot:$PYTHONPATH" python bot/bot/main.py
```

### 3. Убедитесь, что процесс работает

```bash
ps aux | grep main.py
```

Должна быть **одна** строка с `python …/main.py`. Несколько процессов вызовут ошибку `TelegramConflictError`.

---

## 📋 Доступные команды бота

| Команда   | Описание                          |
|-----------|-----------------------------------|
| `/start`  | Приветствие и информация о магазине |
| `/help`   | Список доступных команд           |
| `/status` | Проверка статуса бота              |

Любое другое текстовое сообщение вызовет fallback-ответ с предложением использовать команды.

---

## ✅ Чек-лист тестирования

- [ ] Отправить `/start` → Бот отвечает приветствием + 2 inline-кнопки
- [ ] Отправить `/help` → Бот показывает список команд
- [ ] Отправить `/status` → Бот отвечает «Бот работает нормально!»
- [ ] Отправить произвольный текст → Fallback-ответ с предложением использовать /start или /help
- [ ] Проверить что webhook не установлен (URL пустой)
- [ ] Убедиться что работает только один процесс бота

## 🛑 Остановка бота

- **В терминале:** нажмите `Ctrl+C`
- **Убить процесс:** `pkill -f "bot/bot/main.py"`

## ⚠️ Частые проблемы

| Проблема | Причина | Решение |
|----------|---------|---------|
| `TelegramConflictError` | Несколько процессов бота | `pkill -f "bot/bot/main.py"` и перезапуск |
| `BUTTON_URL_INVALID` | Некорректный URL в `WebAppInfo` | Используйте обычную URL-кнопку (уже исправлено) |
| Бот не отвечает | Webhook мешает polling | Бот автоматически удаляет webhook при старте |
| SSL ошибки | Проблемы с сертификатами | `AiohttpSession` использует `certifi` по умолчанию |
